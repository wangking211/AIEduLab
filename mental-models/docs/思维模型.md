## 1. 复利：时间是朋友还是敌人

**一句话本质**：指数增长的威力不在增长率，而在**指数**——所以它对储蓄是朋友，对负债是敌人。

### 算式

$$F = P(1+r)^t \qquad F_{\text{单利}} = P(1+rt)$$

翻倍时间：

$$t_2 = \frac{\ln 2}{\ln(1+r)} \approx \frac{69.3}{r\%} \quad(\text{口算取 } 72)$$

### 数值（默认参数：1 万元，8%，30 年）

| 量 | 值 |
|---|---|
| 复利终值 | **100,627 元** |
| 单利终值 | 34,000 元 |
| 复利馈赠 | 66,627 元 |
| 本金倍数 | 10.06 倍 |
| 翻倍年数 | 9.01 年（72 法则给 9，误差 −0.07%） |

**关键对比**：复利是单利的 **2.96 倍**。差额全部来自「利息再生利息」——
前 10 年几乎看不出差别，后 10 年拉开一半以上。

### 案例

- **正向**：年化 8%，每 9 年翻一倍。30 年翻 3 次多，1 万 → 10 万。
  拖到 50 年是 46.9 万——**最后 10 年贡献了超过前 30 年的总和**。
- **反向**：信用卡循环利息 18%，4 年翻倍（72/18=4）。
  1 万元欠款 20 年后是 **27.4 万**。

### 常见误用

1. **用单利直觉估复利**（最普遍）：「8% × 30 年 ≈ 2.4 倍」——实际是 10 倍。
2. **低估早期**：前 5 年增长平缓，人们以为"没用"而放弃。但放弃的正是复利曲线的**起点**。
3. **忽略费率**：管理费 2% 对 8% 收益是 25% 的侵蚀，30 年下来终值腰斩。
   芒格的对应原则：**先排除愚蠢**（反过来想）。

### 决策口诀

> 找到 25cm 的鱼塘（长期高复利），然后**别中断**。中断一次 = 归零重来，
> 而复利曲线的价值集中在末端。

## 2. 贝叶斯基率：为什么阳性大多是假的

**一句话本质**：证据（检测）只能**放大**风险，**基率**（先验）决定放大后的绝对水平。
低基率 + 高准确率 ≠ 高后验。

### 算式

$$P(\text{病}\mid +) = \frac{s\,\pi}{s\,\pi + (1-c)(1-\pi)}$$

其中 $s$=灵敏度，$c$=特异度，$\pi$=先验患病率。

等价形式（更易记）：**先验赔率 × 似然比 = 后验赔率**，似然比 $= s/(1-c)$。

### 数值（1% 患病率，99% 灵敏度，95% 特异度，1000 人）

| 格 | 人数 |
|---|---|
| 真阳性（有病且阳性） | 9.9 |
| **假阳性（无病但阳性）** | **49.5** |
| 假阴性（有病但漏诊） | 0.1 |
| 真阴性 | 940.5 |

$$P(\text{病}\mid+) = \frac{0.99\times0.01}{0.99\times0.01+0.05\times0.99} = \frac{1}{6} \approx 16.7\%$$

**阳性中 83.3% 是假的**。似然比 = 0.99/0.05 ≈ **19.8**——检测把风险放大了 16.7 倍，
从 1% 抬到 16.7%，是**有价值的证据，但远不是结论**。

### 案例

- **医学筛查**：在低基率人群做普查必然产生海量假阳性。
  所以筛查只用于**高危人群**——先抬高先验，检测才有意义。
  拖滑块可见：要让后验 > 50%，患病率须超过约 **4.8%**。
- **冤案的数学根源**：把「现场出现过的罕见 DNA」当成 99.99% 有罪证据，
  而忽略「这片区域里有多个无关者的 DNA」这个基率。
  链接概率被误当作后验概率使用。

### 常见误用

1. **基率忽视**：看到强证据就跳过先验。这是人类最高频的认知错误之一。
2. **把灵敏度当后验**：「检测 99% 准确 → 阳性 99% 有病」——完全错误。
3. **忽视证据的相关性**：同一批数据被反复用于更新（重复计数），
   等价于人为放大似然比。

### 决策口诀

> 拿到任何"证据"，先问：**这件事在没证据时本来就有多常见？**
> 基率低到一定程度，任何非完美的检测都救不回来。

## 3. 期望值与凯利：为什么"全押"必输

**一句话本质**：算术期望决定你**是否该参与**，几何增长率决定你能**走多远**。
两者在"下多大仓位"上给出完全相反的答案。

### 算式

期望净收益（每 1 单位）：

$$E = p\,b - q$$

凯利最优仓位：

$$f^* = \frac{bp - q}{b}$$

几何增长率（下注比例 $x$）：

$$g(x) = p\ln(1+xb) + q\ln(1-x)$$

### 数值（60% 概率赢 2 倍，40% 概率输光）

| 量 | 值 |
|---|---|
| 期望净收益 $E$ | **0.8**（每 1 单位） |
| 凯利仓位 $f^*$ | **40%** |
| 半凯利 | 20% |
| 双倍凯利的算术期望 | 1.6（**更高！**） |

**陷阱**：算术期望随仓位**线性增长**——它会一路鼓励你加大仓位。
但几何增长率是**凹**的，在 $f^*$ 处取最大值，超过即转负。

### 关键推演：为什么全押必输

$g(1) = p\ln(1+\infty) + q\ln(0) = -\infty$

只要有一格是「输光」，复利就**永久终结**。全押 100% 时，
需要 4 连胜才保住本金（$0.6^4 = 12.96\%$）。**哪怕期望为正**。

### 案例

- **赌徒 vs 企业家**：赌徒追求单次期望最大化（全押），企业家追求**存活**（留冗余）。
  同样的正期望，前者大概率出局。
- **幸存者偏差**：100 家公司里 10 家百倍回报被广泛报道，90 家破产无人书写。
  只看幸存者，真实期望会被严重高估。

### 常见误用

1. **把凯利当上限而非参考**：凯利假设你能**精确知道** $p$ 和 $b$。
   而人对赔率的估计从不准。
2. **忽视凯利对参数的极端敏感**：胜率高估 5%，最优仓位就要大幅下调。
3. **用算术期望做长期决策**：算术期望只对"只做一次"有效。

### 半凯利：为什么芒格和巴菲特都用它

凯利平方根法则：**仓位减半，长期增速只损失 25%，风险却大幅下降。**

$$g(f^*/2) \approx 0.75\,g(f^*)$$

> 凯利是**上限**，不是目标。

## 4. 安全边际：估计必然出错，所以要留冗余

**一句话本质**：安全边际不是一个固定百分比，而是**估值不确定性 σ 的函数**。

### 算式

名义安全边际：

$$\text{MOS} = \frac{\mu - P}{\mu}$$

**击穿概率**（假设真实价值 $\sim N(\mu,\sigma^2)$）：

$$z = \frac{P-\mu}{\sigma}, \qquad P(V<P) = \Phi(z)$$

### 数值（估价 100，σ=15，买入价 80）

| 量 | 值 |
|---|---|
| 名义安全边际 | **20.0%** |
| 标准分 $z$ | −1.333 |
| **击穿概率** | **9.1%** |

20% 的名义边际下，仍有 **9.1%** 概率实际上买贵了。

### 不确定性才是真正的敌人

同样 20% 边际，把 σ 从 15 拖到 30：**击穿概率跳到 25.2%**。

$$z = \frac{P-\mu}{\sigma} \quad\Longrightarrow\quad \text{同一边际，更大的 } \sigma \text{ 给出更小的 } |z|$$

**结论**：越是看不懂的生意（σ 越大），需要留的边际越大——
这就是为什么巴菲特只买看得懂的生意（**能力圈**），并且在圈内也要留足边际。

### 把边际定量化

想把击穿概率压到 5% 以下，价格须满足：

$$P \le \mu - 1.645\,\sigma = 100 - 24.68 = 75.33$$

> **反过来想的量化版本**：先算出会亏多少概率的价格，再决定买不买——
> 而不是先看好公司，再找理由说服自己价格合理。

### 常见误用

1. **把 MOS 当固定门槛**：格雷厄姆的「至少 1/3」是经验值，不是定律。
   σ 不同的资产，同一门槛的含义完全不同。
2. **只看名义边际，不看击穿概率**：20% 边际 + 大 σ 可能比 10% 边际 + 小 σ 更危险。
3. **用"我看好它"降低边际要求**：看好会**降低你的主观 σ**，这正是危险所在。

## 5. 机会成本：选 A 的真实成本是放弃的 B

**一句话本质**：机会成本永远对照**被放弃选项中最好的那个**，不是最差的，也不是零。

### 算式

$$\text{机会成本} = \max(\text{放弃项}) - \text{所选项}$$

### 数值（选 A=80 万，放弃 B=100 万、C=60 万）

| 量 | 值 |
|---|---|
| 机会成本（放弃的最优） | **100 万** |
| 账面收入 | 80 万 |
| **相对最优替代的净收益** | **−20 万** |

**账面赚 80 万，经济上亏 20 万**。你每天在为"没去 B"付费。

### 关键推演

拖动滑块：A 必须涨到 **100 万以上**，真实净收益才转正。
在此之前，选 A 在数学上就是亏的——**无论你多喜欢 A 的清闲**。

### 常见误用

1. **拿最差方案自我安慰**（最普遍）：「C 才 60 万，我选 A 已经很好了」。
   机会成本对照的是 B（100 万），不是 C。
2. **忘记时间和注意力的机会成本**：你读这本书的机会成本是读另一本更好的书。
3. **只在事后算账**：机会成本本质是**事前排序**工具——
   先列出所有替代方案，取最大值，再决定。

### 决策口诀

> 决策前先问「我放弃了什么」，而不是「我能得到什么」。
> **越优秀的人机会成本越高，越不该随便做事。**

## 6.1 反过来想：最弱环节决定生死

**一句话本质**：成功要走完整条链，失败只需断一环。所以**先问「怎么必然失败」**——
把「存活率」变成一个可以相乘、可以排序的量。

### 算式

系统由 $n$ 个必要环节串联（任何一环失效则全盘失败）：

$$S = (1-p_w)(1-p_r)^{n-1}$$

两种改法的存活率倍数：

$$\text{先堵最弱一环}：\frac{1-p_r}{1-p_w}
\qquad\qquad
\text{全员优化}：\left(\frac{1-p_r/2}{1-p_r}\right)^{n-1}$$

要让存活率过一半，最弱环的失败率必须低于：

$$p_w \le 1 - \frac{1}{2(1-p_r)^{n-1}}$$

### 数值（默认 $n=8$、最弱环 50%、其余各 10%）

| 量 | 值 |
|---|---|
| 整体存活率 $S$ | **23.91%** |
| 整体失败率 $1-S$ | 76.09% |
| 可直接归因于最弱环的失败占比 | 65.7% |
| 先堵最弱一环 → 存活率 | ×**1.80** |
| 其余各环失败率减半 → 存活率 | ×1.46 |
| 存活率上限（最弱环也修到 10%） | **43.05%** |
| 存活率过一半所需的 $p_w$ 上界 | **−0.045（不可能）** |

**关键结论**：把最弱一环从 50% 修到 10%（×1.80），比把其余七环的失败率全部减半
（×1.46）更值钱。而且——**即使最弱环也修好，上限也只有 43.05%，过不了一半**。
$p_w$ 的上界算出是个负数，说明在这个结构下，没有任何办法能让存活率过半。

### 案例

- **投资**：一笔钱要同时通过研究、估值、买点、仓位、持有、退出。与其把每道关卡
  都从 90% 提到 95%，不如先找出失败率最高的那一道。
- **飞行检查单**：起飞前的清单不是为了让飞机「飞得更好」，而是为了让 $p_w$ 里
  不出现接近 1 的项。
- **巴菲特的规则一**：不要亏损。规则二：不要忘记规则一。

### 常见误用

1. **在最好的环节上继续加码**：修一环的边际收益是 $\frac{1}{1-p}$，
   $p$ 越大越值钱；在已经很好的地方优化，收益接近零。
2. **以为「每环都不错」就够了**：8 环各 10% 失败率，整体存活只有 **43.05%**。
   **环节越多，天花板越低。**
3. **把「避免失败」当成保守**：它不是保守，而是唯一能显著提高 $S$ 的操作。

### 决策口诀

> 先列出所有会让这件事**彻底失败**的路径，再问：哪一条最容易发生？先修那一条。

## 6.2 激励优先：佣金决定行为

**一句话本质**：代理人的最优解是**提成的函数**，不是人品的函数。
想改变行为，就改激励结构；说教改变不了任何东西。

### 算式

委托人（顾客）价值 $V(x) = v_{lin}x - v_{quad}x^2$，最优
$x_P = \dfrac{v_{lin}}{2v_{quad}}$。

代理人效用 $U(x) = c\,x - c_{quad}x^2$，最优
$x_A = \dfrac{c}{2c_{quad}}$。

两者重合当且仅当

$$c^{*} = 2c_{quad}\cdot x_P = \frac{c_{quad}\,v_{lin}}{v_{quad}}$$

### 数值（$v_{lin}=100$、$v_{quad}=5$、$c_{quad}=2$、提成 $c=20$）

| 量 | 值 |
|---|---|
| 委托人最优 $x_P$ | **10** |
| 代理人最优 $x_A$ | **5** |
| 错配 $x_A - x_P$ | −5 |
| 顾客价值 $V(x_P)$ | 500 |
| 顾客价值 $V(x_A)$ | 375 |
| **顾客被白损失** | **125**（占最优价值的 **25.0%**） |
| 恰好对齐的提成 $c^{*}$ | **40** |

**对称性**：把提成提到 60，$x_A = 15$ 变成过度推销，顾客**同样**损失 125。
提成太低是消极，太高是过度——两种错法的代价一模一样。

### 案例

- **佣金导向的销售**必然过度推销；**按住院天数收费的医院**必然倾向多留病人。
  这不说明从业者坏，只说明激励结构被设计错了。
- **计件工资**下，工人会找到你意想不到的省力方式（好的或坏的）。
- **基金经理**按规模收费，就会优先做大规模而不是做好回报。

### 常见误用

1. **靠开会强调责任心**：$x_A$ 里根本没有「责任心」这一项。
2. **只调金额不调结构**：把固定工资换成提成，等于把 $c$ 从 0 拉到某个正值——
   代理人会立刻按新公式行动。
3. **假设「他会替我着想」**：两套目标函数不同是结构性的，换一个更勤奋的人也一样。

### 决策口诀

> 看到任何行为，先找背后的激励结构：**激励 &gt; 说教 &gt; 规范 &gt; 法律**。

## 6.3 能力圈：边界比大小重要

**一句话本质**：能力圈的边界就是你愿意承受的 **σ 的边界**。
因为方差是**按平方**进入的，圈外一小块暴露就能主导整体风险。

### 算式

设圈外占比 $w$，两部分估值的相关系数 $\rho$：

$$\sigma = \sqrt{(1-w)^2\sigma_{in}^2 + w^2\sigma_{out}^2
+ 2w(1-w)\rho\,\sigma_{in}\sigma_{out}}$$

击穿概率（接第 4 节）：

$$P(V<P) = \Phi\!\left(\frac{P-\mu}{\sigma}\right), \qquad P = \mu(1-\text{MOS})$$

圈外方差贡献与圈内相等的临界点：

$$w^{*} = \frac{\sigma_{in}}{\sigma_{in} + \sigma_{out}}$$

### 数值（$w=20\%$、$\sigma_{in}=10$、$\sigma_{out}=40$、$\rho=0$、$\mu=100$、MOS = 20%）

| 量 | 值 |
|---|---|
| 组合方差 $\sigma^2$ | 64（圈内）+ 64（圈外）= **128** |
| 组合 $\sigma$ | **11.31** |
| 圈外占的方差比例 | **50.0%** |
| 临界暴露 $w^{*}$ | **20.0%** |
| 标准分 $z$ | −1.768 |
| **击穿概率** | **3.85%** |
| 纯圈内时的击穿概率 | 2.28% |
| 风险放大倍数 | **1.69** |

**关键结论**：圈外只占 **20%** 的仓位，却贡献了 **50%** 的方差——
在 $w^{*} = 20\%$ 这一点上，圈内与圈外的方差贡献恰好相等。
同样留 20% 的安全边际，只要把资产放进圈外，击穿概率就从 2.28% 抬到 3.85%。

### 案例

- **巴菲特只买看得懂的生意**：不是保守，而是把 σ 锁在分母的一个小区间里。
- **「知道边界在哪，比边界有多大更重要」**：能力圈很小但边界清楚，胜过能力圈很大但边界模糊。
- **实操**：对每个决策诚实标注「我知道什么 / 我不知道什么」；
  「不知道」的部分对结果的影响超过 30%，就在圈外。

### 常见误用

1. **用「占比很小」安慰自己**：方差按平方进入，20% 的仓位可能是 50% 的风险。
2. **把「熟悉」当「能力圈」**：熟悉一个行业不等于能估计它的内在价值；
   能不能估准，看的是 $\sigma$，不是接触时间。
3. **把圈画得太大**：边界模糊时，你以为的 σ_in 其实是 σ_out。

### 决策口诀

> 先问「这块我估得准吗」，再问「它占我多少」。**乘起来才是风险。**

## 6.4 Lollapalooza：多个倾向同向叠加

**一句话本质**：同向的心理倾向是**乘**起来的，不是加起来的。
单条倾向看不出问题，问题只在叠加时爆发。

### 算式

单条倾向把冲动放大 $(1+a)$ 倍，$n$ 条**同向**叠加：

$$\text{真实} = (1+a)^{n} \qquad\text{vs}\qquad \text{直觉} = 1 + na$$

超出倍数：

$$\frac{(1+a)^{n}}{1+na}$$

### 数值（4 条倾向、每条放大 50%）

| 量 | 值 |
|---|---|
| 乘法叠加 $(1+a)^n$ | **5.06** |
| 线性直觉 $1+na$ | 3.00 |
| 超出比例 | **68.8%** |
| 实际 / 直觉 | **1.69** |
| 超过线性直觉 2 倍所需条数 | **5 条** |

把过程拆开看：$1.5 \to 2.25 \to 3.375 \to 5.063$——
第 2 条是在 1.5 倍的**底座上**再抬 50%，第 3 条又在前一个结果上抬。
而线性直觉算的是 $1.5 \to 2.0 \to 2.5 \to 3.0$。

### 案例

- **拍卖会**：社会认同 + 竞争心理 + 稀缺感 + 承诺一致 → 非理性高价。
- **促销排队**：稀缺 + 社会认同 → 明知不缺货仍然排队。
- **邪教 / 传销**：权威 + 社会认同 + 承诺一致 + 剥夺睡眠 → 全面控制。

### 常见误用

1. **把同向倾向当成相加**：4 个 50% 不是「3 倍」，是 5.06 倍。
2. **试图「更理性地分析」**：在指数曲线的陡坡上，分析本身也是倾向的一部分。
   识别出「同向叠加」这个**结构**，该做的动作是离场。
3. **只盯单条倾向**：单条时乘法与加法完全相等，所以单看一条永远看不出危险。

### 决策口诀

> 数一数：现在有几条倾向**指向同一个方向**？到 3–4 条就停止找理由，
> 改去找**离场**的理由。

## 6.5 误判清单：把风险指数级压下去

**一句话本质**：清单不能消除倾向，但它能把整条指数曲线**压到 1 以下**——
而且同向倾向越多，清单越值钱。

### 算式

每条倾向被清单拦下的概率为 $h$，$k$ 条同向倾向的**残余放大**：

$$\text{残余} = (1+a)^k(1-h)^k = \big[(1+a)(1-h)\big]^{k}$$

**拦截率**：

$$1 - (1-h)^{k}$$

### 数值（$k=4$、$h=50\%$、$a=0.5$）

| 量 | 值 |
|---|---|
| 不上清单的冲动放大 | **5.06** |
| 上清单后的残余放大 | **0.316** |
| 拦截率 | **93.75%** |
| 风险被压低 | **16.0 倍** |

$h=50\%$ 听起来只是「一份打五折的清单」，但 $k=4$ 条同向倾向时，
它把 5.06 倍的冲动压到了 0.32 倍——**低于 1，也就是净无放大**。

## 7.1 贴现：今天的一块钱比明天值钱

**一句话本质**：内在价值不是现金流的**总和**，而是它们的**贴现**；
而且一多半常常来自「第 N 年之后」那一块——也就是最难验证的那一块。

### 算式

两阶段 DCF：

$$V = \sum_{t=1}^{N}\frac{CF_0(1+g)^t}{(1+r)^t}
+ \frac{1}{(1+r)^N}\cdot\frac{CF_0(1+g)^N(1+g_\infty)}{r-g_\infty}$$

要求 $r > g_\infty$，否则级数发散——「永续增长快过贴现」是不自洽的假设。

### 数值（$CF_0=100$、$g=8\%$、$r=10\%$、$N=10$、$g_\infty=3\%$）

| 量 | 值 |
|---|---|
| 显性期现值合计 | 905.26 |
| 终值现值 | 1224.76 |
| **内在价值 $V$** | **2130.02** |
| 终值占比 | **57.5%** |
| $V(r=11\%)$ | 1841.71 |
| 贴现率 +1 个百分点 → 估值下跌 | **13.5%** |

**关键结论**：估值的一多半靠第 10 年之后的假设。而贴现率只动 1 个百分点，
估值就掉 13.5%——**贴现率的选择比现金流预测更致命**。

### 案例

- **巴菲特**：「内在价值是未来现金流的贴现，没有别的算法。」
- **成长股的脆弱性**：$g_\infty$ 从 3% 调到 4%，分母 $r-g_\infty$ 从 7% 缩到 6%，
  终值直接涨 7/6 ≈ 1.17 倍。一个百分点的永续假设，改写整个估值。
- **反例**：靠终值撑起来的估值，一旦远离假设就崩塌——这正是「能力圈」的用武之地。

### 常见误用

1. **只算显性期**：显性期只占 42.5%，漏掉终值等于漏掉一多半。
2. **把 $g_\infty$ 当成可以随便填的数**：它必须低于长期 GDP 增速，否则隐含「这家公司终将吞掉整个经济」。
3. **用同一个贴现率贴现所有资产**：贴现率是机会成本，不同生意风险不同，$r$ 就该不同。

### 决策口诀

> 先问「这个估值里终值占多少」。**占比越高，越不可信。**

## 7.2 规模优势：大者为什么更大

**一句话本质**：固定成本被产量摊薄，于是规模本身就是护城河——
但优势**收敛**，因为它只能把 $F/q$ 压小，压不到零。

### 算式

$$u(q) = \frac{F}{q} + v$$

固定成本占比降到 10% 所需的规模：

$$q^{*} = \frac{9F}{v}$$

### 数值（$F=1000$、$v=10$、$q=500$、$k=3$）

| 量 | 值 |
|---|---|
| 你的单位成本 $u(500)$ | **12.00** |
| 对手的单位成本 $u(1500)$ | **10.67** |
| 单位成本优势（价格战额度） | **1.33** |
| 成本比 $u(q)/u(kq)$ | 1.125 |
| 固定成本占你单位成本的比例 | 16.7% |
| 占比降到 10% 所需产量 $q^{*}$ | **900** |

对手每卖一件就比你便宜 1.33——他可以把售价压到你的成本线以下，自己仍然赚钱。

### 案例

- **正反馈回路**：更大规模 → 更低单位成本 → 能定更低价格（或更多研发/广告）→ 抢到更大份额 → 更大规模。
- **$q^*$ 是行业门槛**：若行业总容量都到不了 $9F/v$，谁都摊不薄固定成本，规模优势就不存在。
- **反例**：把 $F$ 拉到 0，优势立刻消失——没有固定成本就没有规模效应。

### 常见误用

1. **以为规模优势无限**：它随 $F/q$ 衰减，有天然上限（对比下一节的网络效应）。
2. **只看成本不看需求**：规模大了但卖不掉，$q$ 就是库存不是产量。
3. **忽略「规模不经济」**：管理复杂度、官僚化会让 $v$ 随 $q$ 上升，曲线右端可能翘起来。

### 决策口诀

> 问两件事：**固定成本够不够重？行业容量够不够大到 $9F/v$？**

## 7.3 网络效应：连接数按平方涨

**一句话本质**：用户只按 $n$ 涨，连接数却按 $n^2$ 涨。优势**发散**，
所以网络型生意最后往往只剩一家。

### 算式

$$\binom{n}{2} = \frac{n(n-1)}{2}
\qquad\qquad
\frac{\binom{2n}{2}}{\binom{n}{2}} = \frac{2n(2n-1)}{n(n-1)} \xrightarrow{n\to\infty} 4$$

### 数值（$n=1000$）

| 量 | 值 |
|---|---|
| 连接数 $n(n-1)/2$ | **499,500** |
| 梅特卡夫口径 $n(n-1)$ | 999,000 |
| 用户翻倍 → 连接数 | **×4.002** |
| 100 万条连接所需用户数 | **1,415** |

### 案例

- **电话网 / 社交网络 / 支付网络**：用户翻倍，可连接的对手数翻四倍。
- **同样的 1,415 个人**，两两之间的潜在连接就超过一百万条——所以几千人的网络，
  复杂度已经是百万级的关系数。
- **对比规模优势**：那一个优势收敛（寡头共存），这一个优势发散（赢家通吃）。

### 常见误用

1. **用线性直觉估网络价值**：以为用户翻倍价值翻倍，实际连接数翻四倍。
2. **把「用户多」当网络效应**：真正的判据是「用户之间能不能互相连接」；
   单向的媒体用户规模不是网络效应。
3. **忽略负网络效应**：拥堵、噪音、垃圾信息会让每用户价值随 $n$ **下降**。

### 决策口诀

> 数一数：**用户之间有多少条连接？** 只有连接数才按平方长。

## 7.4 临界点：R₀ 略过 1 就天翻地覆

**一句话本质**：有些系统不是渐变，而是在某个阈值上**换一种行为模式**。
一侧扰动自行消失，另一侧扰动自己放大。

### 算式

SIR 的三个方程（比例之和恒为 1）：

$$\frac{dS}{dt} = -\beta SI \qquad
\frac{dI}{dt} = \beta SI - \gamma I \qquad
\frac{dR}{dt} = \gamma I$$

阈值：

$$R_0 = \frac{\beta S_0}{\gamma} > 1 \;\Longleftrightarrow\; \text{爆发}$$

峰值感染（解析解，$S_{peak} = \gamma/\beta$）：

$$I_{peak} = I_0 + S_0 - S_{peak} + \frac{\gamma}{\beta}\ln\frac{S_{peak}}{S_0}$$

### 数值（$\beta=0.6$、$\gamma=0.2$、$S_0=1$）

| 量 | 值 |
|---|---|
| 基本传染数 $R_0$ | **3.00** |
| 峰值感染比例（解析） | **30.06%** |
| 峰值感染比例（RK4 数值） | 30.06%（与解析差 < 0.01） |
| 最终累计感染 $R_\infty$ | **94.05%** |
| 熄灭所需的易感比例上界 $\gamma/\beta$ | 0.333 |

把 $\gamma$ 从 0.2 拖到 0.65（$R_0$ 从 3 掉到 0.92）：感染数立刻从「一路爬升」
变成「单调下降」，中间**没有过渡**。

### 案例

- **流行病**：疫苗不需要把 $R_0$ 压到 0，压到 1 以下就够（群体免疫）。
- **情绪与舆论**：$\beta$ 是「感染别人的速率」，$\gamma$ 是「冷静下来的速率」。
  远离群聊是降 $\beta$，睡一觉再决定是升 $\gamma$。
- **Lollapalooza 的动力学版**：多个倾向同向叠加，本质就是把 $R_0$ 推过 1。

### 常见误用

1. **线性外推**：在 $R_0 < 1$ 时看到曲线「已经在涨」，就以为它会继续涨。
2. **以为必须清零**：把 $R_0$ 压到刚好小于 1，系统自己就会收敛。
3. **忽视初值**：$R_0$ 只决定**会不会**爆发，爆发的**规模**还取决于开始时的感染基数。

### 决策口诀

> 问一句：**这个系统现在在阈值的哪一侧？** 跨过去，行为模式就变了。

## 7.5 沉没成本：已经花掉的，不该进入决策

**一句话本质**：沉没成本在决策里的系数是 **0**——不是「小」，是零。
而它最危险的伪装，是把两个平衡点悄悄错开。

### 算式

$$E[\text{继续}] = pR - C \qquad (\text{式子里没有 } S)$$

$$\text{正确平衡点} = \frac{C}{R}
\qquad\qquad
\text{误算平衡点} = \frac{C+S}{R}$$

### 数值（$S=100$、$C=50$、$p=40\%$、$R=200$）

| 量 | 值 |
|---|---|
| 正确算法 $E[\text{继续}]$ | **+30** |
| 账面算法 $pR - C - S$ | **−70** |
| 真正的盈亏平衡成功率 $C/R$ | **25.0%** |
| 误算出来的平衡点 $(C+S)/R$ | **75.0%** |
| 两个平衡点之差 | **50.0 个百分点** |

同一个项目，两个符号。而 50 个百分点的差距**完全由沉没成本制造**，
与项目本身毫无关系。

### 案例

- **「已经投了这么多，不能半途而废」**：但半途而废和继续，花的都是未来的钱。
- **「再等等就回本了」**：市场不知道你的成本线在哪。
- **承认错误是信息，不是成本**：它让你更新判断，不改变收益。

### 常见误用

1. **把「沉没」误当成「已投资产」**：能卖掉的不是沉没成本，卖不掉的才是。
2. **用沉没成本提高门槛**：已投入越大，你要求的成功率越离谱，越容易错过划算的事。
3. **在情绪上给它记功**：它看起来像「负责任」，实质是损失厌恶在替你算账。

### 决策口诀

> 只问一句：**如果这笔钱还没花，我现在会投吗？**

## 7.6 冗余备份：串得少，并得多

**一句话本质**：同一个零件，接法不同，结果差三个数量级。
而且**串联那个式子，就是「反过来想」的存活率**。

### 算式

$$\text{串联：}\quad R = r^{n}
\qquad\qquad
\text{并联：}\quad R = 1 - (1-r)^{n}$$

两个门槛：

$$n_{\text{串联掉到一半}} = \frac{\ln 0.5}{\ln r}
\qquad\qquad
n_{\text{并联升到 }99\%} = \frac{\ln 0.01}{\ln(1-r)}$$

### 数值（$r=90\%$、$n=5$）

| 量 | 值 |
|---|---|
| 串联可靠度 $0.9^5$ | **59.05%** |
| 并联可靠度 $1-0.1^5$ | **99.999%** |
| 并联 / 串联 | **1.69 倍** |
| 串联掉到 50% 所需零件数 | 6.58（即第 7 个） |
| 并联升到 99% 所需零件数 | **2** |

串联 7 个就和抛硬币差不多；并联只要 2 个就到 99%。

### 案例

- **减少串联环节**：一件事如果需要连续过关，每加一环都在做乘法削减。
- **给关键环加并联**：多个供应商、多份备份、多重验证、多条收入来源。
- **分清结构**：很多失败不是环节不够好，而是把本该并联的东西串起来了。

### 常见误用

1. **只提高单件质量**：把 $r$ 从 90% 提到 99%，串联门槛从 7 个放宽到 69 个——
   但并联只要 1 个就够。**冗余通常比重质更便宜。**
2. **给非关键环加冗余**：冗余要加在「全坏才坏」的那个位置上，也就是单点故障处。
3. **忘记冗余本身的成本与故障率**：备份也要钱、也会坏，切换机制本身也可能失灵。

### 决策口诀

> 先画结构：**这件事是「必须全部成功」，还是「只有一个成功就行」？**
> 前者先找最弱的一环，后者先多备几条路。

## 8. 大分叉：人类是在 1820 年前后分手的

> **这一节与前 16 个模型不同：它不是公式驱动，而是数据驱动。**

前 16 节里，每个数都由 `lib/models_kernel.py` 用 sympy 推出。但历史不是推导出来的，
是**记录**下来的。所以这里的纪律换成同样严格的一条：**不手写数据**。

| 项 | 值 |
|---|---|
| 数据来源 | Bolt & van Zanden (2024), Maddison Project Database 2023，经 Our World in Data 轻度加工 |
| 单位 | **international-$（2011 年价）** |
| 覆盖 | 公元 1 – 2022 年 |
| 抓取 | `scripts/fetch_maddison.py`（sha256 校验；源站一更新就拒绝继续） |
| 出处 / 许可 | `data/SOURCES.md`（CC BY 4.0；含 MPD 归属要求指定的**逐国原始论文**） |

### 算式：把复利公式反着用

第 1 节的复利是 $F = P(1+r)^t$。解出 $r$，就得到量历史用的**年化增长率**：

$$r = \left(\frac{V_1}{V_0}\right)^{1/T} - 1$$

只要给我「起点值、终点值、年数」，任何一段历史都能换算成一个可比的数。

### 数值：以 1820 年切成两段

| 国家 | 前段 | 前段年化 | 后段 | 后段年化 | 加速 |
|---|---|---|---|---|---|
| 英国 | 1000 → 1820 | **+0.1288%** | 1820 → 2022 | **+1.2215%** | ×9.5 |
| 法国 | 1 → 1820 | +0.0351% | 1820 → 2022 | +1.5326% | ×43.7 |
| 美国 | 1650 → 1820 | +0.6446% | 1820 → 2022 | +1.5391% | ×2.4 |
| 日本 | 730 → 1820 | +0.0725% | 1820 → 2022 | +1.6819% | ×23.2 |
| 中国 | 1000 → 1820 | **−0.0401%** | 1820 → 2022 | +1.5377% | — |
| 印度 | 1600 → 1821 | **−0.1354%** | 1821 → 2022 | +1.0577% | — |

再取两个具体窗口（页面默认与一个长窗口）：

| 窗口 | 英国 | 中国 |
|---|---|---|
| 1820 → 2020（200 年） | 1.1817%/年，×10.48 | 1.4971%/年，×**19.53** |
| 1000 → 2020（1020 年） | 0.3344%/年 | 0.2595%/年 |

**关键结论**：1820 年之前的一千八百年里，最发达地区的人均收入年化不到 0.7%；
而**中国与印度是负的**——不是「增长得慢」，是**人变多了、人均更穷了**。

### 读法的三条纪律

1. **别把「起飞」当必然。** 在对数轴上，1820 年前的一切几乎是一条水平线。
   复利不是自然常数，它是近代才启动的机制。
2. **倍数最小的那行最难读。** 美国的「加速」只有 ×2.4，不是因为它慢，
   而是它 1650 年的起点就有 897 国际元、前段本身已跑了 0.6446%。**看倍数之前先看起点。**
3. **这是基率，不是预言。** 这一节回答「历史上通常长什么样」，
   不回答「接下来会怎样」。**用历史建立基率，不用历史预测下一次** ——
   这正是第 2 节贝叶斯那一页要的输入，也是芒格说的「用基率，不用记忆」。

### 案例

- **为什么 1820 年是个分界**：工业革命、化石能源、复利式的资本积累在此前后
  从「零星」变成「可持续」。数据不需要解释原因，但它把分界点指了出来。
- **为什么落后者能追上**：中国 1820 → 2022 是 ×19.53，是六国里最大的倍数 ——
  起点越低，同样的年化增长率带来的倍数越大。
- **与第 1 节的闭环**：复利那一页说「时间是朋友还是敌人」；
  这一页给出历史证据：对绝大多数人类历史而言，**时间既不是朋友也不是敌人，它根本不发生**。

### 常见误用

1. **把早期估算当成精确数字**：1820 年前的点多为学术估算、年份不连续
   （中国 1000–1820 仅 44 个点，印度 1600 年前没有数据）。**结论在量级上稳健，在小数点后不稳健。**
2. **拿它做预测**：「过去 200 年年化 1.5%，所以接下来也是」——这是外推，不是基率。
3. **忽视口径拼接**：1990 年前用 1990 年 PPP、2011 年起用 2011 年 PPP，中间做了平滑衔接；
   跨 1990 边界的增速带有方法学痕迹。
4. **不看起点只比倍数**：倍数最大的往往不是增长最快的，而是起点最低的。

### 口诀

> 问历史要的是**分布**，不是**方向**：
> 「这种事以前出现过多少次、结果分布如何」，比「上次之后发生了什么」有用得多。

## 9. 决策前检查清单

在做任何**不可逆**或**大额**决策前，逐条过一遍：

### 第一层：数学（可量化）

- [ ] **期望值**：每个选项的 $p \times b - q$ 是多少？概率估得准吗？
- [ ] **仓位**：如果长期重复，我下注的比例是多少？超过凯利的 1/2 了吗？
- [ ] **击穿概率**：我的估计如果错了，错到什么程度会击穿？概率多少？
- [ ] **机会成本**：被放弃的**最优**选项是什么？扣掉后我的净收益还是正的吗？
- [ ] **复利位置**：这个决策是在积累复利，还是在中断复利？
- [ ] **存活率**：这件事要连续通过几个环节？最弱的那一环失败率多少？
      （8 环里最弱 50%，整体存活只有 **23.9%**——先修最弱那一环，存活率 ×**1.80**）
- [ ] **能力圈暴露**：我是在评估它，还是在猜它？
      （圈内 σ=10、圈外 σ=40 时，**20%** 的圈外仓位就贡献 **50%** 的方差）

### 第二层：认知偏差（定性）

- [ ] **反过来想**：这个决策会导致失败的路径是什么？我避开了吗？
- [ ] **基率**：这件事在没证据时本来就多常见？我是不是只看了代表性？
- [ ] **激励**：推荐我这么做的人，他的激励结构是什么？
      （提成 20 时代理人只做到 5，而顾客想要 10，顾客白损失 **25%**——这是算术，不是人品）
- [ ] **能力圈**：这是在我圈内还是圈外？圈外的部分对结果影响多大？
- [ ] **可得性**：我是不是因为"最近听到/看到很多"而高估了概率？

### 第三层：清单与退出

- [ ] **Lollapalooza**：是否有 2 个以上倾向同时指向同一方向？
      （稀缺 + 社会认同 + 权威 = 高度警惕信号）
- [ ] **同向叠加**：现在有几条倾向指向同一个方向？
      （4 条各 50% 的倾向叠起来是 **5.06 倍**，不是直觉里的 3 倍）
- [ ] **承诺一致**：我是否因为已经公开表态/投入而难以退出？
- [ ] **损失厌恶**：我是否因为"不想承认亏损"而坚持一个已经变坏的决策？

- [ ] **清单落到纸上**：这 25 条我逐条问过了吗？
      （每条拦截率 50% 时，4 条同向倾向的拦截率是 **93.8%**，风险被压低 16 倍）

### 第四层：系统与结构

- [ ] **贴现**：这个估值里终值占多少？（默认参数下 **57.5%**——一多半靠远期假设）
- [ ] **规模 / 网络**：护城河属于哪一种？
      （规模优势按 $F/q$ **收敛**，网络效应按 $n^2$ **发散**——后者才会赢家通吃）
- [ ] **临界点**：这个系统现在在阈值哪一侧？（$R_0$ 跨过 1 就换一种行为模式）
- [ ] **沉没成本**：如果这笔钱还没花，我现在会投吗？（已投入的系数是 0）
- [ ] **冗余备份**：这件事是「必须全部成功」还是「一个成功就行」？
      （前者先找最弱环，后者多备几条路）

### 最后一问

> **如果把这个决策重复 100 次，我会怎样？**
> 一次性的运气，长期看必然回归期望。
> 凯利和安全边际存在的全部理由，就是让你**活到**回归发生的那天。

## 10. 常见误用汇总表

| 模型 | 最常见的误用 | 正确做法 |
|---|---|---|
| 复利 | 用单利直觉估复利 | 用 72 法则快速校准；关注末端贡献 |
| 贝叶斯 | 把灵敏度当后验概率 | 先写基率，再套公式 |
| 期望值 | 用算术期望做长期决策 | 改用几何增长率；用半凯利 |
| 凯利 | 当上限用，满仓 | 当上限的 1/2 用；参数宁可悲观 |
| 安全边际 | 当固定百分比门槛 | 作为 σ 的函数计算击穿概率 |
| 机会成本 | 对照最差方案 | 对照被放弃的**最优**方案 |
| 反过来想 | 在已经很好的环节上继续加码 | 先修失败率最高的那一环 |
| 激励 | 靠说教改变行为 | 改提成结构，或换计酬方式 |
| 能力圈 | 用「占比很小」安慰自己 | 记住方差按平方进入：20% 仓位可能是 50% 风险 |
| Lollapalooza | 把同向倾向当成相加 | 识别同向叠加，动作改为离场 |
| 误判清单 | 存在脑子里当原则 | 写在纸上逐条问，才有拦截率 |
| 贴现 | 只看显性期现金流 | 先看终值占比；占比越高越不可信 |
| 规模优势 | 以为它无限 | 优势随 F/q 收敛，还有规模不经济 |
| 网络效应 | 用线性直觉估网络价值 | 数连接数，它按 n² 涨 |
| 临界点 | 线性外推、以为必须清零 | 判断在阈值哪一侧；压到 R₀<1 即止 |
| 沉没成本 | 把已投入算进期望 | 只问「如果还没花，我现在会投吗」 |
| 冗余备份 | 只提高单件质量 | 在单点故障处加并联，通常更便宜 |
| 大分叉 | 拿历史外推未来 | 用它建立基率与分布；先看起点再看倍数 |
