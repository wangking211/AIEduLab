# 建模与写作约定

## 一、单一数据源：一切数值来自 kernel

**永远不要心算，也永远不要在讲解文字里硬编码数字。** 所有数值都由 `lib/bio_kernel.py`（sympy 精确）
在**默认参数**下算出，再插进讲解文字；滑块驱动的量用表达式字符串交给浏览器实时求值。

```python
import bio_kernel as K
s = K.cross_summary("Aa", "Aa")          # 基因型 1:2:1、表现型 3:1（精确）
"…所以基因型比例 " + s["genotype_ratio"] + "。"     # ✅ 引用 kernel
"…所以基因型比例 1:2:1。"                            # ❌ 手写数字，改动时会不一致
```

这样保证：**讲解文字 ↔ 画板读数 ↔ 状态灯**三者任何时候都自洽。

## 二、遗传学表示约定（最容易出错的地方）

### 基因型字符串
- 二倍体、每基因两个等位基因：`"AaBb"`、`"AABb"`、`"aa"`。
- 同一个**字母**（不分大小写）属于同一个基因，**大写为显性**。
- `parse_genotype` 会自动分组，无需指定基因边界。

### 表现型表示（每基因 2 字符）
`phenotype_of` 输出**每基因两位**：显性存在记 `A_`，否则记 `aa`。

| 基因型 | 表现型 |
|---|---|
| `AaBb` | `A_B_` |
| `Aabb` | `A_bb` |
| `aaBb` | `aaB_` |
| `aabb` | `aabb` |

这样才能写通配匹配：`progeny_prob(跨, "A_bb", by="phenotype")`。

### 比例排序
`cross_summary` 的**基因型/表现型列表按字符串排序**（`AA < Aa < aa`、`A_B_ < A_bb < aaB_ < aabb`），
这正是教科书里棋盘格的顺序，所以 `ratio_str` 会给出熟悉的 `1:2:1` / `9:3:3:1` / `3:1`。
**不要**改成按份数排序——那样会得到 `2:1:1` 这种反直觉写法。

### 比例要**约分**
`Aa × aa` 的份数是 `Aa=2, aa=2`，但显示必须是 `1 : 1`。`ratio_str` 已按最大公约数约分，
所以**引用 `ratio_str` 的结果**，不要自己拼 `2 : 2`。

### 伴性遗传
- 母亲写 `"XAXa"`（4 字符），父亲写 `"XAY"`（3 字符）。
- `sex_linked_cross` 返回 `{daughters, sons}` 两个分布；儿子的 X 只能来自母亲。
- 表现型判断用 `x_linked_affected(gt)`（本例以 `A` = 正常、`a` = 致病）。

### 棋盘格必须 `equalAspect: true`
否则在竖长画布上格子会被拉成长方形。配好 `_punnett_scene()` 后由它自动带上。

## 三、代谢计算约定

- **摩尔质量用教学整数**：$M(CO_2)=44$、$M(H_2O)=18$、$M(O_2)=32$、$M(C_6H_{12}O_6)=180$ g/mol。
  这样 264 g CO₂ → 6 mol → 180 g 葡萄糖，数字干净；用 44.01 会得到一串小数。
- `photosynthesis_balance(…)` 内部会校验 C/H/O 原子守恒（反应物侧 vs 产物侧），守恒不成立就报错。
- **呼吸作用就是光合作用的逆反应**，讲课时对照着讲，用同一套数。

---

## 四、生态约定

- 能量传递效率默认 10%（自然范围 **10%~20%**）；`energy_pyramid` 用等比数列 $E\eta^{i}$。
- 种群增长：J 型 $\lambda^t$ 必须让它在图上**冲出图外**（yMax 取 $K \times 1.25$）；
  若按 J 型终值定 yMax，S 型会被压平到看不见。
- S 型的两个关键点一定要标注：**环境容纳量 $K$**、**增长速率最大处 $N=K/2$**（最大速率 $rK/4$）。

---

## 五、画板场景的常见坑

1. **多实例排布**：同一个 `geom` 的多个实例务必给不同 `pos`，否则会重叠。
2. **标签出框**：文字标签一律用**像素偏移**画（`ctx.fillText` + 像素坐标），不要用世界坐标偏移——
   不同量纲的两轴（如"年"与"元"、"数量"与"时间"）世界偏移会小到看不见或被裁掉。
3. **轴名与结论抢位**：坐标轴名在轴下方（`ay+24px`），结论文字请放到**图内左上**或**底部再往下**，
   不要和轴名画在同一像素行（会叠字）。
4. **窄层标签**：金字塔/条形图里层很窄时，标签放**条形外侧**（名称在左、数值在右），
   不要放在条形内部。
5. **x/y 比例尺**：board 模板默认 x/y **独立缩放**（因为两轴量纲常不同）；只有棋盘格用 `equalAspect`。
6. **`view` 会被 scene 覆盖**：要动态视图范围就在 `scene` 里写 `xRange`/`yRange` 表达式。

## 六、三入口（给定题 / 随机 / 图片）

1. **文字题**：抽取亲本基因型（或营养级能量、生长参数），直接调 kernel。
2. **图片**：用视觉读图抽取题干，**把识别到的信息回显给用户确认**（亲本基因型、性状显隐关系、单位）
   再继续；显隐性关系没写全时按常规假设并明确告知。
3. **随机出题**：`generate.py random` 从遗传/生态/代谢里挑一题，参数规整（比例用对称的杂交组合）。

> **输出语言跟随提示词语言**：英文提示 → 英文网页，中文 → 中文。

## 七、交付纪律

- **成品写用户指定的输出目录**（默认在用户 cwd），**绝不写技能自身的 `output/`**——
  那是开发样例，随技能一起分发。
- 生成后自检：`python lib/bio_kernel.py`、`python lib/cell_library.py` 都要打印 `OK ✓`。
- 浏览器复核（可用 `browser` 工具）：**0 控制台报错**、**0 `.katex-error`**、画板有像素、
  滑块拖动后读数改变、状态灯会切换、定值指示与滑块无关。
- 细胞 3D 页额外看：`renderer.info.render.triangles > 0`（几何确实画了）、
  分步切换后高亮的细胞器 `opacity=1` 而其余 `≈0.12`。
