# 解法配方与自检约定（conventions）

## 总原则

1. **单一数据源**：首项、公差、公比、通项、前 n 项和、周期、最值点、三角形三边
   三角与面积全部由 `seq_kernel.py` 精确算出（sympy 有理数/根式/pi），模型只组织
   讲解文字。绝不在 `steps` 里心算数字。
2. **规整优先**：参数取能出整数/简单根式答案的值（等差 a5=14,a10=29→d=3；
   等比 a1=3,q=2→S5=93；裂项 1/(k(k+1))→S10=10/11,极限 1；错位 q=2→S4=49；
   递推 2a_n+1→a_n=2^n−1,a5=31；sin 波 A=2,ω=3,φ=π/6→T=2π/3,最高点 x=π/9；
   SAS b=2,c=3,A=60°→a=√7,面积=3√3/2；恒等式 ±60°→cos60°=½ 抵消干净）。
3. **交互必有验证点**：每题至少一个高亮读数 + 一个 `status` 状态灯；能恒定/恒等的
   配 `constant` 定值指示（d≡3、q≡2、极限 1、周期 T≡2π/3、恒等式 ≡ sinθ）。
4. **角度统一**：kernel 里 `solve_sin_wave` 的 φ 用**弧度**（`sp.pi/6`），
   `solve_sas` 的 A 用**度数**（60）——看清函数签名；场景字段 `phi` 是弧度、
   `Ad` 是度数；readouts 里 `A*PI/180`、`x*180/PI` 负责换算。

## 建图约定

- **世界坐标 y 向上**；seq/tri 页 view `[0,10]×[0,6.5]`，wave 页 `[0,10]×[0,6.2]`。
- **seq 双面板**：上半（y 3.5~6.0）画 Sₙ 折线、下半（y 0.7~2.9）画 aₙ 柱；
  两组数据各自按最大值归一，量纲不同没关系——这是**趋势对比**不是同一坐标系。
  `limit` 参与 Sₙ 面板缩放（×1.05 保证虚线在面板内）。
- **柱高只画正半轴**（下沿从基线向上）；负通项（本技能不会出现）需改 abs。
- **wave 的振幅缩放**：`AS = 2.05/max|A|`，多曲线时按最大振幅统一缩放，
  保证 ±A 虚线与曲线都在 y=0.5~5.5 内。
- **tri 顶点布局**：A(4,1) 起笔，AB 沿 +x，AC 逆时针转 Ad——b=2,c=3 时
  x∈[2.1,7]、y∈[1,3]，15°~165° 全程不出画板。
- **状态灯阈值**：恒等/恒成立用 `op:"<"` + 小量（0.001 数列、1e-6 三角恒等式、
  0.01 内角和）；"是否最值"用 `abs(abs(y)−A)` 与 0.005 比。
- **三元表达式**：readouts 的 expr 支持 JS 三元，可用于分段（本技能暂未用到）。

## 自检清单（每题交付前）

1. `python lib/seq_kernel.py` 全部 assert 通过。
2. `build_*` 内断言 kernel 答案与已知规律一致（S10=155、S5=93、S4=49、
   a5=31、T=2π/3、a=√7、恒等式化简为 0）。
3. 答案卡 `lesson.answer` == 末步骤展示值 == 画板读数初值（同源）。
4. 本地服务预览：无 console 报错、KaTeX 无 `.katex-error`；拖滑块到关键点
   （n 端点、x=π/9 最高点、A=90° 面积极值、θ=0/90/270°）读数与状态灯正确翻转；
   定值读数保持恒定；画布非背景像素占比 >1% 且随滑块变化（像素哈希不同）。
5. 成品写到 cwd（技能目录的 `output/` 只放仓库样例）。

## 常见坑

- **GBK 控制台**：Windows 下 print ✓ 会 UnicodeEncodeError，先 `PYTHONIOENCODING=utf-8`。
- **f-string 花括号**：Python f-string 里 LaTeX 的 `{...}` 必须写成 `{{...}}`
  （`y_{\max}` → `y_{{\max}}`，`_{{n}}` 同理），否则 SyntaxError。
- **multi 数组对象内不求值**：`wave` 的 `multi` 元素是对象，模板不走进数组逐元素
  求值分支——`phi` 必须在 Python 侧用 `f(sp.pi/3)` 算成数字，写 `"PI/3"` 串会
  在 `Math.sin` 里变 NaN、曲线消失。
- **滑块 step 截断**：验证时给 `x=3.1415` 而 step=0.01 会被吸附成 3.14，
  读数 xd=179.9° 而非 180.0°——这是 step 行为不是 bug；要精确关键点就让
  step 能整除该值（如 π/9≈0.349 用 step 0.01 时给 0.349 会吸附 0.35，
  y=2.000 显示正常因为阈值 0.005）。
- **递推 partial 数组**：`recurrence` 的 Sₙ 是 a_k 前缀和（不是闭式再取样），
  用 `sum(terms[:i])` 与 kernel 闭式对拍。
- **状态灯文字含单位**：`A+B+C = 180° ✓` 的 ° 是 okText 里写死的，
  换题时别漏，也别在 okText 里塞表达式。
- **rAF 隐藏暂停**：标签页不可见时动画暂停（`animT` 不涨）；本技能三种场景
  全由 param 驱动、静态首帧即正确，不受影响。
