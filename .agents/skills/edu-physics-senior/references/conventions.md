# 解法配方与自检约定（conventions）

## 总原则

1. **单一数据源**：加速度、时间、位移、速度、力、功、动能、向心力全部由
   `mech_kernel.py` 精确算出（sympy 有理数/根式），模型只组织讲解文字。绝不在
   `steps` 里心算数字。
2. **常量固定**：高中惯例 `g = 10 m/s²`（kernel 顶部 `G_ACC`；题目另有指定则改传参）。
3. **规整优先**：参数取能出整数/简单根式答案的值（v0=4/带速=1/μ=0.2→a=2,Δs=9/4；
   θ=30°/μ=0.2→a上=5+√3；m=2,F=10,μ=0.1→a=4；r=0.4,v=2→F向=10）。
4. **交互必有验证点**：每题至少一个高亮读数 + 一个 `status` 状态灯；能守恒/恒定的
   配 `constant` 定值指示（Δs_max、vx、v临、f=μmg），能分配的配 `bars` 能量条。

## 建图约定

- **世界坐标 y 向上**；view 按场景内容外扩（多数 10×6.4）。
- **世界单位 ≠ 米**：多数场景把"米"缩放后放进画板。
  - belt：物块位移 ×0.8 加初偏移 1.0（3.75m→约 4 世界）。
  - chase：×kx=0.2（数十米的公路压进 9 世界；`kx` 字段控制刻度）。
  - ramp：×2.4（s_max 2.67m→6.4 世界，斜面长 8.6）。
  - projectile：**g、v0、h0 全部 ÷5** 后传入场景（20m→4 世界），真实值经
    `hdisp`/`Hdisp`/readouts 显示——否则轨迹飞出画板。
  - ground：×1（位移 ≤8m 直接当世界）。
  - circle：r=0.4m 用 2.0 世界画圆；readouts 里的 F_c=mv²/r 用**真实 r=0.4**。
- **力箭头标度**（fscale）每题单独标定：力值跨 2~60N，需保证初值下箭头清晰且
  不撑爆画面（0.03~0.35 不等）；模板对每支箭头有 `min(…, 上限)` 封顶保护。
- **三元表达式**：场景字段与 readouts 的 expr 支持 JS 三元（`t<1.5 ? a : b`），
  用于分段运动（belt 减速/匀速、ramp 上滑/下滑、ground 静摩擦/滑动摩擦）。
- **分段切换点用浮点近似**（0.891、1.485、2.17 等）：kernel 的精确值
  （如 t_up=6/(5+√3)）取 3 位小数写进 JS 表达式，显示层 2 位小数看不出差异。
- **状态灯阈值**：`op:">"` 配 `rhs:0` 判断速度正负（上滑/下滑、在空/落地、
  F>f/推不动）；`op:"<"` 配小量（0.01）判断"相等/成立"。

## 自检清单（每题交付前）

1. `python lib/mech_kernel.py` 全部 assert 通过。
2. `build_*` 内断言 kernel 答案与已知规律一致（划痕极值、Δxmax、s_max、T=60N）。
3. 答案卡 `lesson.answer` == 末步骤展示值 == 画板读数初值（同源）。
4. 本地服务预览：无 console 报错、KaTeX 无 `.katex-error`；拖滑块到关键点
   （共速时刻、速度相等时刻、最高点、落地、临界 F、最低点、滑块端点）读数与
   状态灯正确翻转；定值读数保持恒定；能量条比例正确；画布非背景像素占比 >1%。
5. 成品写到 cwd（技能目录的 `output/` 只放仓库样例）。

## 常见坑

- **GBK 控制台**：Windows 下 print ✓ 会 UnicodeEncodeError，先 `PYTHONIOENCODING=utf-8`。
- **f-string 花括号**：Python f-string 里 LaTeX 的 `{...}` 必须写成 `{{...}}`，
  否则 SyntaxError 或被当表达式求值（`x_{\mathrm{带}}` → `x_{{\mathrm{{带}}}}`）。
- **平抛缩放**：若把真实 g=10、v0=10 直接当世界值，2s 轨迹横向 20 世界远超画板
  （宽仅 10）——必须同比缩小 g/v0/h0（本模板 ÷5），并保留真实值读数。
- **分段常数不一致**：同一题的三元表达式各分支常数必须来自同一组 kernel 输出
  （曾出现 v0=10 的 s_max 与 v0=6 的 t_up 混用，导致 t=0.89 时 s 错为 6.23）。
- **ramp 世界缩放**：`s_blk`（世界）与 `sdisp`（真实）要同时给，标注才显示真实米数。
- **circle 的角度**：param 用度数（0~360 直观），场景字段 `theta` 用弧度
  （`theta*PI/180`）；T 公式 `mv²/r − mg·cosθ` 中 θ 从最高点量起。
- **rAF 隐藏暂停**：标签页不可见时动画暂停（`animT` 不涨），是浏览器行为；
  本技能多数场景由 param 驱动、静态首帧即正确，不受影响。
- **静摩擦表达式**：ground 场景 `f_fric: "F<=2 ? F : 2"`——静摩擦随外力增大、
  滑动后恒为 μmg；写成常数 2 会让 F<2 时的"推不动"教学点失真。
