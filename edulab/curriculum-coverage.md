```
  B6  热化学（盖斯定律）  ← 高中内容，清单原先漏列

  C5  统计推断 ✅

  A2  计算机技能分层
  B4  集合、逻辑与不等式（优先级最低）
```

**排序理由**：
1. ~~A1 只需扩题型（内核与场景已有），成本最低~~ —— 已完成；
2. B1 是**必修内容缺失**，且 ①A 比例高、与解析几何/力学有交叉但不重复；
3. B2 补齐高中物理的另外三册，使物理成为完整学科；
4. C1 经济学是全新学科，可算比例高，用户已确认要做。

## 四、每条都要守的纪律（与既有技能一致）

1. 不手写数字；读数表达式与内核逐条对账。
2. 动画/轨迹必须真跑；有解析解的一律与解析解对照。
3. 出处分级：现算 / 实测 / 假设，假设逐条列出。
4. 证据力分级（`edu-history` 起）：模型 ≠ 结论，参数靠估的必须标注。
5. 画板单参数契约；文字用 `labelIn`；曲线用裁剪版绘制函数。
6. 新技能必须在 `SKILL.md` 里写「什么时候不该用本技能」并指向替代。
