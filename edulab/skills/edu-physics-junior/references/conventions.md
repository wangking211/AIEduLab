# 解法配方与自检约定（conventions）

## 总原则

1. **单一数据源**：力、压强、浮力、拉力、效率、电流、电压、功率、热量全部由
   `phys_kernel.py` 精确算出（sympy 有理数），模型只组织讲解文字。绝不在
   `steps` 里心算数字。
2. **常量固定**：初中惯例 `g = 10 N/kg`、`ρ_水 = 1.0×10³ kg/m³`（kernel 顶部
   `G_ACC` / `RHO_WATER`）；单位换算（cm²→m²、×10⁻⁴ m³）必须在 kernel/步骤里显式写出。
3. **规整优先**：参数取能出整数/简单分数答案的值（600N·0.06m→36、12N/50cm²→2400Pa、
   400+100)/2→250N、6V/10Ω→0.6A、5+10Ω→4V/8V）。
4. **交互必有验证点**：每题至少一个高亮读数 + 一个 `status` 状态灯；
   能整除/守恒的配 `constant` 定值指示（F₁L₁=F₂L₂、F浮+F拉=G、U₁+U₂=U、Q=W），
   能分组成的配 `bars` 能量条（W有/W额 80%/20%）。

## 题型配方表

| 题型 key | 已知设置 | kernel 函数 | 场景 kind | 核心交互 | 验证点 |
|---|---|---|---|---|---|
| `lever` | 撬棒撬 G=600N 石块，L2=0.06m，F1=24N | `solve_lever(F1,L2,F2)` | `lever` | 滑块改动力臂 L1 → 杠杆倾斜 | F₁L₁ vs **F₂L₂≡36 N·m**，平衡灯变绿 |
| `pressure` | 砖 F=12N 平放 S=50cm² | `solve_pressure(F,S,S_unit)` | `pressure` | 滑块改 F → 海绵下陷深度 | p=F/S 读数；作用效果灯（>4000Pa 变红） |
| `buoyancy` | 石块 G=4N，V排 拖到 2×10⁻⁴ m³ | `solve_buoyancy(rho,V,G,F_scale)` | `buoyancy` | 滑块改 V排 → 物体下沉、三力箭头 | F浮=2N；**F浮+F拉≡G=4N**；全浸时悬浮灯 |
| `pulley` | G=400N，G动=100N，n=2，h=1m | `solve_pulley(G_obj,G_moving,n,h)` | `pulley` | 滑块改 h → 重物上升、绳端下移 | F≡250N、**η≡80%**；bars 400/100 J |
| `ohm_law` | U=6V，R=10Ω | `solve_ohm(U,R)` | `circuit` single | 滑块改 R → 电流点变密/疏 | I=0.6A；**I·R≡6V** 欧姆定律灯 |
| `series` | U=12V，R1=5Ω，R2=10Ω | `solve_series(R1,R2,U)` | `circuit` series | 滑块改 R1 → U1/U2 重新分配 | I=0.8A，U1=4V，U2=8V；**U₁+U₂≡12V** |
| `parallel` | U=6V，R1=6Ω，R2=3Ω | `solve_parallel(R1,R2,U)` | `circuit` parallel | 滑块改 R1 → 支路点流速差异 | I1=1A，I2=2A，I=3A；**I₂≡2A** 不受影响 |
| `elec_power` | U=6V，R=10Ω，t=100s | `solve_elec_power(U,R,t)` | `circuit` single | 滑块改 t → W、Q 同步增长 | P≡3.6W；**Q≡W**（纯电阻灯） |

## 建图约定

- **世界坐标 y 向上**，view 按场景内容外扩（力学 9×6，浮力 10×7，电路 9.5×6.2）。
- **力箭头**：长度 = 力 × `fScale/fs1/fs2`，封顶 1.6 世界单位——力值跨 4~600N，
  必须每题单独标定，保证初值下箭头清晰且不撑爆画面。
- **杠杆**：真实力臂（L2=0.06m）与绘图臂长（d2=1.7）分离，标注显示真实值；
  `tilt` 由失衡量驱动，平衡时水平。
- **压强**：下陷深度 `sink = p × 0.001cm/Pa × 0.08世界/cm`，`k=0.08` 供 `Δ` 标注
  换算回 cm；限幅 `min(…, sh*0.85)` 防止画穿海绵底。
- **浮力**：`objTop` 表达式控制下沉（如 `3.1 + 1.05*(1-V/0.0004)`：V=0 在液面上方，
  V=V全 浸没）；浸没段自动深色（引擎按液面裁剪）。
- **滑轮**：`my = myBase + h×1.6`、`handY = 3.4 − h×0.85`（s=2h 的视觉近似）；
  绳子路径为锚点→动滑轮→定滑轮→手的折线+圆弧。
- **电路**：布局固定，只传 `layout` + 元件值 + 电流表达式；并联各支路各自
  `flows`，流速 ∝ 支路电流（分流可视化）。`kflow` 取 1.6~2.0 使点可见移动。

## 自检清单（每题交付前）

1. `python lib/phys_kernel.py` 全部 assert 通过。
2. `build_*` 内断言 kernel 答案与已知规律一致（分压和=总压、并联电流反比、Q=W）。
3. 答案卡 `lesson.answer` == 末步骤展示值 == 画板读数初值。
4. 本地服务预览：无 console 报错；拖滑块读数/状态灯正确翻转；定值读数保持恒定
   （F₂L₂=36、F浮+F拉=4、U₁+U₂=12、η=80%、Q=W）；能量条比例正确；电路有流动点。
5. 成品写到 cwd（技能目录的 `output/` 只放仓库样例）。

## 常见坑

- **GBK 控制台**：Windows 下 print ✓ 会 UnicodeEncodeError，先 `PYTHONIOENCODING=utf-8`。
- **单位换算**：面积 cm²→m²（÷10⁴）、体积 ×10⁻⁴ m³，写错会差 10⁴ 倍——kernel 断言可捕获。
- **力箭头标度**：fScale 漏配或沿用他题数值，箭头会不可见或溢出；每题按力值范围重标定。
- **杠杆 d1/d2**：直接用真实 L1/L2 作绘图臂长，阻力臂会贴在支点上看不见；
  必须给 `d1/d2` 示意长度，标注仍显示真实值。
- **rAF 隐藏暂停**：标签页不可见时电流点不流动（`animT` 不涨），是浏览器行为；
  验证动画需聚焦标签页，静态首帧渲染不受影响。
- **滑轮 η 的 0/0**：`h=0` 时 η 表达式为 0/0 → 读数显示 `—`，可接受；
  若要避免，把滑块 min 设为 0.05。
- **浮力全浸**：滑块上限取 V全（F浮=G，悬浮灯变绿）；超过会使 F拉 变负（物理无意义），
  上限务必卡在 V全。
