# 建模与写作约定

## 一、唯一真源：kernel 真实执行

这个技能和别的 edu-\* 技能最大的不同：**动画不是画出来的，是跑出来的。**

`lib/cs_kernel.py` 里每个算法都是真正的 Python 实现，执行时用 `Trace` 把每一步
状态快照录进 `steps`。模板拿到 `steps` 后按进度滑块逐帧回放。
所以：

- **永远不要手写 steps**。要用哪个算法，就调 kernel 里对应的函数。
- 讲义里的数字（比较几次、交换几次、结果是什么）也必须来自 kernel 的返回值，
  用 f-string 插进去；不要凭记忆写「大约 n²/2 次」。
- 这样「画板看到的」和「文字写的」天然一致，改一个参数两边一起变。

## 二、控制台：滑块必须真的接上东西

左栏滑块的唯一职责是**实时重算读数**。三条硬规矩：

1. **滑块不能是摆设**。如果拖到底读数一动不动，那就是设计事故
   （`generate.py verify` + 离线冒烟测试都会检查「读数是否随参数变化」）。
   想让某页有滑块，就先想清楚「拖动它，哪个量会变」。
2. **优先做「复杂度控制台」**：一个规模 `n`，配 `ops`（本算法操作数）、
   `lin`（线性的参照值）、`sec`（按 1e8 次/秒折算的耗时），
   再加一个「相对线性算法的倍数」当定值。学生一拖就明白「阶」意味着什么。
3. **读数可以链式引用**：`sec = ops/1e8` 依赖前面算出的 `ops`。
   这比让每个表达式各算一遍干净得多。

### 每页至少一个「定值不变量」或「状态灯」

定值要挑**与参数无关、或随参数单调变化**的量，用来暴露不变量或临界条件：

- 位运算页：`(a&b) + (a|b) === a + b`（恒真，跨参数不变）
- 栈/队列页：`'最后进的最先出'`（规则本身）
- 哈希页：装填因子 `α = 键数/桶数`（拖动桶数实时变）
- 二分页：`lg(1e9) ≈ 30`（提醒对数的威力）

## 五、写作约定

1. **复杂度必写**。每个算法都要在 `answer` 或 `pills` 里给出时间/空间复杂度，
   并在控制台体现出「阶」的差距。只讲实现不讲代价，是这类课件的通病。
2. **讲「为什么」，不只讲「怎么做」**。`explain` 里至少有一块回答
   「这个策略凭什么是对的」。例如：
   - Dijkstra：为什么「取 dist 最小者锁定」是安全的？（边权非负）
   - 贪心区间：为什么按**结束**时间排而不是开始时间？（交换论证）
   - 二分：为什么必须有序？（否则无法判断该丢哪一半）
3. **给出反例**。贪心要说明它**什么时候会失效**（`[1,3,4]` 凑 6）；BST 要说明
   有序插入会退化成链表。让读者知道边界在哪。
4. **不夸大**。说「平均 O(1)」就不要写成「O(1)」；哈希、快排都要点明最坏情况。
5. `intro` 里明确告诉读者**看哪里**（「橙色是正在比较的一对，青色是已就位」），
   否则动画只是热闹。

## 六、JSON 安全的坑（务必遵守）

模板与生成器之间是 JSON 传递，有几处必须显式转换：

- **无穷**：用 `null`，**不要**用 `float("inf")`（`json.dumps` 会产出 `Infinity`，
  不是合法 JSON）。Dijkstra 的 `dist` 就是这么处理的。
- **不要往 lesson 顶层塞字典/数组**：顶层只放标量与 `counters`，
  其余结构一律进 `scene`。否则「统计」卡片会出现 `[object Object]`。
- **列表 vs 标量**：很多高亮字段在不同算法里既有「数组」形态也有「单值」形态
  （`visit` 是字符串、`visited` 是数组）。模板已做兼容，但**新写渲染逻辑时**
  要沿用 `Array.isArray` 判别的写法。
- **下标 vs 值**：`bars` 的 `cmp/swap/sorted` 是下标；BST 的 `path` 是**值**。
  模板的 `treeModel()` 会按需翻译，别在生成器里再翻译一遍（会双重转换）。

## 七、自检清单

改完任何一页，按顺序跑：

```bash
python lib/cs_kernel.py            # 内核自检（算法本身对不对）
python scripts/generate.py verify  # 注册表 + 契约校验（id / 表达式 / 场景字段）
python scripts/generate.py all ./out
```

再用离线冒烟测试把每一帧都过一遍（见 `SKILL.md` 末节）：
桩掉 Canvas 与 DOM，`setFrame(0..n-1)` + 参数推到极值，任何渲染器异常都会暴露。

最后在浏览器里**真的拖一下滑块**：读数变了才算接上，没变就是摆设。
