# 数据格式参考（problem-schema）

与 `edu-physics-junior` / `edu-function-derivative` 的 schema 同源（`lesson` / `steps` /
`board` 三段），本文档重点列**本技能新增/有差异**的部分。通用结构（param 滑块、
readouts、constant 定值指示、legend 图例、bars 能量条、scalars 逐帧标量）见
`../edu-physics-junior/references/problem-schema.md`。

**本技能画板是"力学场景"而非几何曲线**：`board.view` 只提供世界坐标范围
（xRange/yRange，y 向上），核心是 `board.scene`（场景 kind + 场景字段）。

## 1. scene 通用规则

```jsonc
"scene": { "kind": "belt",           // 七种之一：belt/chase/ramp/projectile/ground/circle/vt
           "caption": "…画板标题…",   // 画板右上角说明
           "vbelt": 1,               // 数值字段：数字 或 含 param/scalars 名的表达式
           "xblk": "1.0+0.8*(t<1.5 ? (4*t-t*t) : (3.75+(t-1.5)))" }
```

- 所有数值字段按 `{p: 滑块值, <param名>: 滑块值, ...scalars}` 求值；字符串求值
  非有限数时保留原串（故 `kind`/`caption` 可安全写字面量，三元表达式也支持）。
- **世界坐标 y 向上**，与初中模板一致；x/y 用世界单位（非米），需按场景换算。
- `readouts` 类型：`expr`（求值显示，`highlight` 高亮）、`status`
  （`expr op rhs` → `okText` 绿 / `badText` 红，`op` ∈ `< <= > >= ==`，
  省略 op 时为 `>=`）。
- `bars`：`{label, a:{label,expr}, b:{label,expr}}` 双色能量条（宽度按占比，内显数值）。
- `constant`：`{label}` 静态定值指示（KaTeX），如 "Δs_max ≡ 2.25 m"。

## 2. 七种场景字段

### kind: `belt`（水平传送带）
| 字段 | 含义 |
|---|---|
| `vbelt` | 带速（m/s，箭头方向由其符号定） |
| `xblk` | 物块中心的**世界 x 坐标**（表达式；含初位置偏移） |
| `boxW` | 物块绘图宽度（世界单位） |
| `vblk` | 物块速度（m/s，正负定箭头方向，显示值） |
| `ffric` | 滑动摩擦力（N，负=向后；滑动段 ±μmg，共速后 0） |
| `fscale` | 力→箭头长度标度（世界/N，如 0.35 使 2N→0.7 世界） |
| `scratchPx` | 划痕的**世界长度**（画在带面上的红色虚线） |
| `xbeltStart` | 划痕起点的**世界 x**（通常=物块初位置） |
| `scratchLen` | 划痕**真实米数**（标注文本用） |
| `phase` | 静态说明文字（画在左上；不能是表达式） |

### kind: `chase`（追及相遇，双车公路）
| 字段 | 含义 |
|---|---|
| `kx` | 米→世界 的缩放（世界单位/米；位置数十米时必配，如 0.2） |
| `xA`/`xB` | 两车位置（**真实米数**，画图时 ×kx） |
| `vA`/`vB` | 两车速度（m/s，仅箭头与标签） |
| `t` | 当前时间（左上角显示） |

刻度每 10 m 一格自动绘制；间距标注显示真实米数。

### kind: `ramp`（斜面滑块）
| 字段 | 含义 |
|---|---|
| `rampLen` | 斜面绘图长度（世界单位） |
| `theta_deg` | 倾角（度） |
| `s_blk` | 沿斜面位置的**世界长度**（通常 = 真实 s × 缩放） |
| `sdisp` | 沿斜面**真实米数**（标注文本用，可省略则用 s_blk） |
| `v_blk` | 速度（m/s，正=上滑，负=下滑；定箭头方向与长度） |
| `G`/`N`/`f_fric` | 重力/支持力/摩擦力（N，驱动三支箭头；f 沿斜面反速度方向） |
| `boxW` | 物块边长（世界） |
| `fscale` | 力→箭头标度（如 0.06 使 20N→1.2 世界） |

### kind: `projectile`（平抛/斜抛）
**注意：本场景的世界单位是"缩放后的米"**——把真实 g、v0、h0 同除以一个长度缩放
（如 5），保证轨迹落进画板；真实值经 `hdisp`/`Hdisp` 或 readouts 显示。
| 字段 | 含义 |
|---|---|
| `h0` | 抛出点**世界高度**（真实 h0 ÷ 缩放） |
| `g` | **世界重力加速度**（真实 g ÷ 缩放） |
| `v0` | **世界初速度**（真实 v0 ÷ 缩放） |
| `theta_deg` | 抛射角（0=平抛） |
| `t_total` | 轨迹虚线采样的总时长（略大于落地时间） |
| `t` | 当前时间（=param） |
| `vscale` | 速度→箭头长度标度 |
| `H` | 最高点**世界高度**（0 表示平抛无升高，跳过虚线） |
| `Hdisp` | 最高点**真实米数**（标注用） |
| `hdisp` | 当前高度**真实米数**表达式（标注用） |
| `t_peak` | 到最高点时间（预留） |

### kind: `ground`（水平面滑块：牛二 / 动能定理共用）
| 字段 | 含义 |
|---|---|
| `x_blk` | 物块中心**世界 x**（= x_start + 位移×缩放） |
| `x_start` | 起始**世界 x**（位移标注左端） |
| `s_blk` | 位移**真实米数**（标注文本 + dimLine 门限） |
| `v_blk` | 速度（m/s，定箭头方向与长度） |
| `F`/`f_fric` | 拉力/摩擦力（N；F 向前、f 向后箭头） |
| `G` | 重力（N；同时画 N=G 向上小箭头） |
| `m` | 质量（标签显示） |
| `boxW` | 物块宽度（世界） |
| `fscale` | 力→箭头标度；`vscale` 速度→箭头标度 |
| `t` | 当前时间（左下角显示；动能定理页可用表达式如 `sqrt(s/2)`） |

### kind: `circle`（竖直圆环绳模型）
| 字段 | 含义 |
|---|---|
| `r` | 半径**世界长度**（真实 r 单独在 readouts 里算） |
| `theta` | 位置角（**弧度**，0=最高点；用 `theta*PI/180` 把 param 度数转来） |
| `clockwise` | 布尔（false=逆时针约定；直接传 JSON 布尔，不求值） |
| `v` | 速度（m/s，表达式按机械能守恒给，如 `sqrt(vtop²+2gr(1-cosθ))` 的世界/真实一致值） |
| `F_c` | 向心力（N，= mv²/r 表达式；箭头指向圆心） |
| `m`/`g` | 质量/重力加速度（mg 箭头用） |
| `vscale`/`fscale` | 速度/力→箭头标度 |

### kind: `vt`（v-t 图像）
| 字段 | 含义 |
|---|---|
| `tmax` | t 轴最大值（图宽映射） |
| `vmin`/`vmax` | v 轴范围 |
| `vt_pts` | 折线点数组 `[[t,v],[t,v],…]`（匀变速为两点直线；数组不求值） |
| `t` | 当前时间（游标竖线 + 当前点） |
| `s_blk` | 当前位移（"阴影面积=位移"标注文本） |

## 3. 读数与验证点设计

每题至少：**1 个高亮 expr 读数 + 1 个 status 状态灯**；能守恒/恒定的配 `constant`；
能分配的配 `bars`（如动能定理 W_F vs |W_f| 83.3%/16.7%）。

## 4. 三入口归一

| 入口 | 处理 |
|---|---|
| 文字题 | 抽取已知/所求/单位 → 匹配 `conventions.md` 配方 → kernel 求解 |
| 图片 | 视觉读图识别题面，回显确认后同上 |
| 随机 | `generate.py random [seed]`：随机选题型（8 种等概率） |
