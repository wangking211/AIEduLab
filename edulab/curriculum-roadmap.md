## 二、大学扩展：能不能做

**能，而且比初高中更适合做**——大学理工内容以「可算」为主，①-a（纯数学/恒等式、
随处可算、成本极低）的比例显著高于中学。中学要花大量力气把「不可算的知识点」
翻译成可算模型，大学内容本身常常就是公式。

| **线性代数**（18.06 Strang） | 矩阵变换、行列式＝面积/体积比、特征值与不变量方向、秩与零空间、正交投影/最小二乘、Gram–Schmidt、SVD、二次型与正定 | **网格线性变换动画**（单位圆→椭圆＝奇异值；单位方→平行四边形＝行列式） | 极强（`Matrix.det/eigenvals/svd/nullspace`） | **①-a 首选** |

### 不建议做的大学方向

- **纯数学的分析/代数**（实分析、抽象代数、拓扑）：命题的证明过程不是「给定参数
  → 输出数值」的函数，图只能承载直觉而非论证 → ③ 为主。做也只能做有限的特例演示。
- **文科与社科的理论课**：同 `coverage-audit.md` 的 ③ 结论。
- **依赖不可复现实验的科目**：违反「动画必须真跑」纪律。

## 三、建议顺序

**先把 `edu-probability` 做了**——它一项同时补上高中概率统计的空白**和**大学的
概率论入口，是性价比最高的单点。其次 `edu-chem-calc`（补中学化学计算的空白），
再进大学线的 `edu-linear-algebra`。

```
初高中收尾:  edu-probability  →  edu-chem-calc  →  edu-geography  →  edu-history
大学线:      edu-linear-algebra  →  edu-ode-dynamics  →  edu-signals
             （edu-probability 已顺延到大学，无需重复）
```

> **初高中收尾已全部完成。** 下一步进大学线。

**`edu-history` 的特殊纪律**：历史学的立身之本（史料批判、因果论证、动机推断）
落在 ③ 层，不可形式化。所以该技能只做 ① 层，并**强制每一页标注证据力等级**：
①A 纯数学/恒等式、①B 模型参数靠估、①C 形态①证据力③（可被拟合，最危险）。
没有徽章的页不许出 —— `_evid_badge()` 在构建期强制。

**已确立的三个可复用机制**（后续技能照用）：
1. **读数表达式 ↔ 内核逐条对账**：`generate.py` 里的 `_agree()` 在构建期用等价的
   Python 实现求值一次再比对，公式漂移当场停构建。经验证它已三次抓到真错
   （JS 的 erf 逼近漏了除以 √2；`_js_to_py` 需要剥外层括号才能递归三目；
   `declination(172)=23.4398` 与常量 23.44 的 2e-4 偏差）。
2. **跨语言逐位一致的伪随机**（32 位 LCG）：让浏览器里随滑块重跑的模拟
   与内核录下的是**同一条随机序列**。`edu-probability` 的实测证据：
   大数定律末值 0.49145 == 0.49145，CLT 样本均值差 0.0e+00。
3. **模拟量在浏览器真跑、理论量由内核现算**：两者用同一个输入契约，
   读数只放理论值，图上只放真跑结果 —— 避免两套实现互相漂移。

**已经踩过、必须显式检查的四类坑**：
1. 模板里「参数驱动的字段」要写成参数字符串（如 `"n": "n"`）。漏写会让画板拿到
   `undefined` 抛错，而 `render()` 在 `updateReadouts` 之前中断 ——
   读数全变「—」，看起来像「没数据」而非「有 bug」。`edu-chem-calc` 抓到过。
2. **取整语义**：Python 的 `round()` 是银行家舍入，JS 的 `Math.round` 不是。
   涉及取整一律写 `floor(x+0.5)`。`edu-geography` 的时区号抓到过。
3. **滑块 `value` 必须落在 `step` 网格上**：不自洽时浏览器会**悄悄吸附**初始值，
   页面上「题设值」根本拖不到。自检要读回 `input.value` 核对。
   `edu-geography` 的默认经度因此从 87.6° 改成 116°。
4. **长注释顶出画布**：右侧一列用 `start` 对齐的文字最容易溢出；
   自检要量像素包围盒的四周余量，不能只看「有没有内容」。
   `edu-probability`（探测点标签）、`edu-chem-calc`（55 字注释）、
   `edu-geography`（换算说明）各抓到一次。
   **已给出通用修法**：`edu-history` 的 `labelIn()` —— 先按当前 `sc`
   用 `ctx.measureText` 量宽，再按对齐方式把锚点收进画布。后续技能请直接用
   `labelIn`，不要再手工试位置。
5. **只在默认档自检会漏**：`edu-history` 的 `transition` 页峰值标签**只在滑块低端**
   才顶出画布。自检必须扫多个档位（至少含两端）。
6. **状态灯文案是纯文本**：`updateReadouts` 用 `textContent` 写入读数，
   `$…$` 不会被 KaTeX 渲染，会原样显示成 `$R_0$`。状态文案不要写 LaTeX。
7. **滑块的参数范围必须落在模型的有效域内**：`edu-history` 的 `transition`
   把 `mid_b` 下限从 1900 收到 1930 —— 低于 1920（死亡率中点）时模型前提被破坏，
   增长率从窗口起点就单调下降，「峰值年」退化成窗口边界（那是产物，不是结论）。
   **看下限的一条通用判据**：参数取到端点时，读数是否仍然是模型想说的那个量。
8. **LaTeX 花括号在「普通字符串」里不能写双份**：只有 f-string 里 `{{ }}` 才表示
   `{ }`；隐式拼接里没有 `f` 前缀的那些片段，`{{ }}` 会**原样**进入 LaTeX，
   变成「组里套组」——`\begin{{pmatrix}}` 会让 KaTeX 抛
   `Expected node of type textord, but got node of type ordgroup`，
   而整页 `throwOnError:false` 又不把它当错误。
   **通用自检**：对生成页逐个 `$…$` 片段做 `renderToString(frag,{throwOnError:true})`
   —— 只有这条能抓到。`edu-linear-algebra` 抓到 2 处（61 个字符串字面量需修正）。
9. **画几何图形必须裁剪**：线性变换会把点推到极远（剪切 k=2 时能到 ±21），
   网格直接顶出画布。`edu-linear-algebra` 给出了通用工具：`laSegClip`（线段，
   Liang–Barsky）与 `laClipPoly`（凸多边形，Sutherland–Hodgman），
   外加按可见范围自适应的 `laAxes`。后续画几何的场景请直接用这三个。
10. **三目翻译器要能处理括号内嵌套**：`edu-chem-calc` 的 `_js_to_py` 只扫顶层，
    遇到 `2-(cond?1:2)` 会失败。`edu-linear-algebra` 的版本会定位三目所在的
    括号组边界，支持任意深度。新增分段读数时请用后者。
11. **数值闭式解里的 `cosh/sinh` 是陷阱**：`edu-ode-dynamics` 的过阻尼解写成
    $e^{-\zeta t}[y_0\cosh(\omega_h t)+\cdots]$ 时，$\omega_h t=848$ 直接
    `OverflowError`，而且它是两个巨大指数项相减、数值上也不稳。要改写成两个
    指数项**之和**。**通用判据**：闭式解里凡出现 `cosh/sinh` 或两个大数相减，就该改写。
12. **不稳定平衡点附近的轨道会指数发散**：`edu-ode-dynamics` 的相平面在 $k>0$ 时
    轨道 14 年能涨到 $10^6$，不裁剪就直接冲出绘图框。已给出
    `plotPolyClip`（世界坐标下的折线裁剪），画轨道时一律用它。
13. **花括号问题已入闸门**：`check_skills.py` 新增 `brace_literal_check()` ——
    对每个技能的 `scripts/generate.py` 用 tokenize 扫非 f-string 字符串，
    查 `\\begin{{` / `\\end{{`。判据**刻意收窄**：实测（KaTeX 0.16.8）只有环境名
    这一处会失败，`\\mathbf{{v}}`、`\\dfrac{{a}}{{b}}`、`\\operatorname{{tr}}`、
    `x^{{2}}`、`\\sqrt{{10}}`、`\\text{{abc}}` 这些「组套组」**全部正常** ——
    过宽的判据会把一批渲染正常的技能误报成坏（第一次实现时误报了 14 个）。

## 四、每项的硬门槛（与本项目既有纪律一致）

1. **不手写数字**：全部由 sympy 内核现算，答案卡 = 末步值 = 画板读数初值，四者同源。
2. **动画真跑**：数值积分/随机模拟必须真执行并录下步骤，不得编造轨迹。
3. **方向类结论现算**：不靠记忆（如洛伦兹力 `F=qv×B`、稳定性由特征值符号判）。
4. **出处分级**：每个数字标注「现算 / 实测 / 假设」，假设逐条列出。
5. **画板单参数契约**：一个滑块驱动，其余固定。
6. **题型数 ≥ 6**，且画板形态与既有技能可辨识地不同（否则应并入现有技能）。
