# factreg.py —— 事实登记守则（库）+ 每本书的 facts.py（数据）

> 一句话：**书里每个数都要能回答「你是从哪来的」。**
> 答不上来的，要么改成 `@@记号@@` 由内核现算，要么在登记表里登记清楚。

## 为什么需要它

「不手写数字」在本项目里早就有了，但它此前只覆盖**图形**（`figures.py` 现算）。
正文里的年份、尺度、比例仍然可以手写，写错了没人管。而一本讲「万物尺度」的书，
最危险的失败模式不是算错，而是**数字看着精确、来源经不起追问**：

> 「宇宙年龄 138 亿年」——是测出来的？推出来的？还是从别处抄来的？
> 误差多少？换一个测量团队会不会变成 128 亿？

`shared/facts.py` 把「一个数从哪来」变成登记项，`tools/check_facts.py` 负责强制。

## 四个等级，各自的义务

| 等级 | 含义 | 必须给 |
|---|---|---|
| **现算** | 由本仓库的内核算出来的 | `recompute`：一个无参函数，闸门**真的调用它**并比对 |
| **实测** | 观测/实验测出来的 | `source` + `url` + `uncertainty` |
| **文献** | 从文献里取的一个确定值/结论 | `source` + `locator`（页码 / 表号 / DOI） |
| **约定** | 只能约定（单位定义、取整规则、演示参数） | `note`：写清「为什么只能约定」 |

`claim(...)` 在**构造时**就检查该等级的必填项，缺了当场抛 `KeyError` —— 不留到闸门。

## 用法

```python
from factreg import Registry, claim

REGISTRY = Registry("宇宙尺度")  # 放在 books/<书>/facts.py 里

REGISTRY.add(claim(
    "age_universe", 13.797e9, "年", grade="实测",
    source="Planck 2018 结果 VI（A&A 641, A6）表 2，TT,TE,EE+lowE+lensing",
    url="https://doi.org/10.1051/0004-6361/201833910",
    uncertainty=0.023e9,
    texts=["138 亿年"],          # 允许正文里这样写
))

REGISTRY.add(claim(
    "light_year", 9.4607304725808e15, "米", grade="现算",
    recompute=lambda: 299792458.0 * 365.25 * 86400.0,
))
```

正文里用 `@@age_universe@@` 引用（渲染管线与图形记号是同一套），
或者写成登记过的字面串 `138 亿年`。**两者之外的数字，闸门一律报红。**

## 判据

| 代码 | 管什么 | 红了说明 |
|---|---|---|
| **F1** | 登记表自身的必填项 | 有人绕过了 `claim()` 手改 dict |
| **F2** | 现算级：当场复算并比对 | 登记的数和内核算出来的**不一致** |
| **F3** | 记号与登记表双向对齐 | 正文引用了没登记的记号；或登记了却没人用（死条目） |
| **F4** | 正文里的未登记数字 | 有数字没交代来源 |

`F4` 连**年份**也不放过（「1838 年」「1799 年」都是事实）。豁免的只有两类：
`$…$` 行内数学、`@@记号@@`，以及结构性编号（`图 10.1`、`第 8 章`、`(1)`）。

## 白名单：必须逐条给理由

```python
REGISTRY.allow_pattern(r"^\d+ 个例子$", "这一章在讲『三个例子』的讲法，不是事实量")
```

`allow_pattern` 的 `why` **必填且至少 8 字**。白名单就是「已批准的不一致」——
批准可以，但不许无声地批准；否则下一个人会以为这些数字已经被核查过了。

## 现状（诚实记录）

- 新书**从第一章起**强制：没有 `facts.py` 的书不接入闸门，但会被**点名**。
- 现有书稿 `books/math-thought` 体检结果：**228 个正文数字没有登记来源**
  （`python tools/check_facts.py --audit books/math-thought`）。
  这不是说那些数字错了，而是说它们**经不起追问** —— 旧书的历史包袱，
  不因闸门存在而消失。这也是新书必须先立这道闸门再开写的原因。

## 跑

```bash
python tools/check_facts.py --selftest              # 负向测试：每条判据都要能红
python tools/check_facts.py                         # 核查所有带 facts.py 的书
python tools/check_facts.py --audit books/math-thought   # 只体检，不判红
```
